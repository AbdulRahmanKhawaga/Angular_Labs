## Overview
The Angular User List project is a web application designed to display a list of users with their details, including name, email, phone number, and verification status. The application allows users to search through the list using various criteria and provides a responsive and user-friendly interface.

## Features
- **User Search**: Search users by email.
- **Responsive Design**: Optimized for both desktop and mobile devices.
- **Verification Status**: Display verification status with visual indicators.
- **Reset Functionality**: Easily reset search criteria.

## Technologies Used
- **Angular**: Framework for building the application.
- **Bootstrap Icons**: For icons used in the UI.
- **TypeScript**: Language used for development.
- **HTML/CSS**: For structuring and styling the application.
