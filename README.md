# 🧪 TypeScript Lab - Product Interface & Generics

<img src="https://miro.medium.com/v2/resize:fit:1358/1*moJeTvW97yShLB7URRj5Kg.png" alt="Angular logo" width="200"/>

This lab demonstrates foundational and intermediate TypeScript concepts including **interfaces**, **union types**, **generics**, and **conditional logic** based on API results.

---

## 📋 Lab Objectives

- Define a `Product` interface with common properties.
- Create a function to log product details.
- Use union types for flexible return types.
- Work with generics to build reusable utilities.
- Use a generic interface to model API responses.
- Bonus: Implement a function to conditionally print product info based on API success.
