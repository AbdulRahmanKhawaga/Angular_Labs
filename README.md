# Angular Labs 🚀

This repository contains lab solutions for an Angular course. Each lab is maintained in a **separate branch** and organized for clarity and isolation.

## 📁 Structure

- The `main` branch contains this `README.md` file and serves as an entry point to the repository.
- Each lab is:
  - Maintained in its own **branch** (e.g., `typescript-1`, `typescript-2`, `angular-1`, `angular-2`, etc.)
  - The branch contains only the files for that specific lab, directly in the root (not in a subfolder).
