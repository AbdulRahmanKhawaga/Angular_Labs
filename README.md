# 🌐 Angular Course Labs Repository

This repository contains lab solutions for an **Angular course**.  
Each lab is maintained in a **separate branch**, structured for clarity, isolation, and ease of navigation.

---

## 📁 Repository Structure

- The **`main` branch** contains only this `README.md` file and serves as the entry point to the repository.
- Each **lab** is:
  - Maintained in its **own branch**, such as:
    - `TypeScript_Lab1`
    - `Angular-Lab1`
    - `Angular-Lab2`
    - etc.
  - Contains **only the files for that specific lab**, placed directly in the **root directory**.

## 🛠️ How to Access a Lab

To view or work with a specific lab:

1. Click the **Branch** dropdown menu on GitHub (above the file list).
2. Select the branch corresponding to the lab you want to explore.
3. The branch will show only the files for that lab.

> 💡 You can also clone or download a specific lab branch using:
>
> ```bash
> git clone -b TypeScript_Lab1 https://github.com/AbdulRahmanKhawaga/Angular_Labs.git
> ```
