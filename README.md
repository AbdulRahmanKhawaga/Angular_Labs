# Angular Portfolio

A modern, responsive portfolio web application built with Angular. Showcase your projects, skills, and professional profile with a clean and interactive design.

## Features
- Hero section with profile image and introduction
- Portfolio section to display your projects with images and descriptions
- Skills section with proficiency bars
- Responsive layout for all devices
- Easy customization for your own content

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/)
- [Angular CLI](https://angular.io/cli)
